## ⚙️ Установка и настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. Настройка конфигурации

Отредактируйте `config/settings.json` под ваши нужды:

```json
{
  "excel": {
    "file_path": "Baza-3dhunyuan.xlsx",
    "target_status": "#",
    "completed_status": "+"
  },
  "browser": {
    "headless": false,
    "timeout": 30000
  },
  "timeouts": {
    "upload_wait": 60000,
    "between_uploads": 5000
  }
}
```

### 3. Подготовка файлов

- Убедитесь, что Excel файл содержит столбцы: `BAZA_ID`, `BAZA_PHOTO_1`, `BAZA_PHOTO_2`, `BAZA_PHOTO_3`, `BAZA_PROFILE`, `BAZA_GOTOVO`
- Разместите cookie файлы в папке `cookies/` (Cookies-01.json до Cookies-10.json)
- Разместите изображения в папке `Upload/` с именами вида `3d-{ID}.jpg`

## ⚠️ Устранение проблем

### Частые ошибки

**Ошибка: "Excel файл заблокирован"**
- Закройте Excel файл перед запуском скрипта

**Ошибка: "Cookie файл не найден"**
- Убедитесь, что файлы Cookies-01.json до Cookies-10.json существуют

**Ошибка: "Изображения не найдены"**
- Проверьте папку Upload/ и соответствие имен файлов

### Восстановление после сбоя

1. Проверьте логи в папке `logs/`
2. Посмотрите последний отчет метрик
3. При необходимости восстановите Excel из резервной копии
4. Перезапустите скрипт

## 🔄 Миграция со старой версии

1. **Сохраните данные**: Старая версия автоматически перемещена в папку `Старое/`
2. **Настройте конфигурацию**: Отредактируйте `config/settings.json`
3. **Проверьте файлы**: Запустите валидацию файлов
4. **Тестовый запуск**: Протестируйте на небольшом количестве записей
